一、AIGC 平台后端（e-commerce-backend）——这个月的安全重头戏

如果说上月学会”防御性编程”，这月就是把网关安全体系彻底立起来。commit 密度最高的都在这里。

1.1 接入与鉴权（OAuth / HMAC / 中央身份）

  • OAuth2 AJAX 授权：授权流改走 AJAX，JWT 增昵称字段，移除 URL token 透传
  • OAuth 内置兜底 + originFromRequest：按来源（9011/9012/9014 多入口）回跳正确登录出口
  • 脚本通道 HMAC 鉴权：脚本调网关先做 HMAC 签名校验（核心 + 配置开关 + 说明文档）
  • 接入中央身份服务边界：OAuth2 授权码携带权威身份 claim，走 fail-closed（校验不过即拒），并跨环境 rollout seam（默认禁用灰度过渡）

1.2 风控与限流

  • API 分级限流：Redis 固定窗口，从”一刀切”升级为分级，附说明文档
  • 风险验证码：L3 / captcha_on_risk 超限自动触发人机验证，补单测与 preflight
  • Web 请求体 AES-256-GCM 加密：网关解密的端到端链路

1.3 权限与正确性打磨

  • EC 租户设备隔离：修复跨租户越权查询，收敛敏感日志
  • 菜单权限同步：恢复 permissionHandling，沉淀 code:-2 权限根因手册
  • keyword_topic_person（话题获客）：修复 PostgreSQL 数组参数、改用 SQL 聚合替代内存计算防大数据量内存溢出、优化 target/list 查询、改为用户私有模式
  • 抖音统计：粉丝/点赞/作品当日未上报时回退显示最近非空值，避免伪 0 值误导
  • 性能与交付：/file/download 支持 stream=1 流式播放（绕开 OSS 预签名过期）、RPC Success 支持 map[string]string、新增 resource_capability 资源评估服务

1.4 部署与排障

  • 8/15 部署 SOP：AI 本体镜像重建 + 9012 前端 + pro1 红绿部署、EC.Host 迁 8098 云控（A 本体+9012 完成，C 块挂起）
  • TikTok 出码 504：禁 keep-alive + 失败重试修复
  • 每周排障笔记补录：9011/9014 权限、RPC 超时蓝绿、AutoDL 视频克隆 GPU、promotion 冷启动等

二、AIGC 平台前端（e-commerce-frontend + ecf-main-deploy）

两块仓库内容同源（ecf-main-deploy 是前端部署镜像），合起来看：

2.1 托管系统（养号/获客/视频发布）——从无到有

  • 发布前人工审核：弹窗展示视频/账号/提示词，一键通过
  • 今日执行记录分页 + 审核通知：短信（恢复可用）/邮箱（新增）/飞书（暂挂）
  • 托管浮标 & 每日配置入口：聊天页右侧高亮浮标，待审核数量角标
  • 前端健壮性：浮标限高从 max-h-screen→max-h-full→fixed+vh 连续三次调优防溢出；TimePicker 修复；开启按钮 loading 防重复点击

2.2 流式体验升级

  • 流式思维链实时渲染：思考/调度链肉眼可见，渲染完自动收起
  • 任务路径实时步骤 + 步骤自动推进：done 后自动收尾
  • 会话列表过期标记 + 推理过程展示
  • 会话侧栏折叠、输入框齿轮设置抽屉

2.3 其他亮点

  • upstream-video 模块迁移进 GenerateVideoV2Drawer，删旧模块
  • 商品画像参考视频库集成、拖图新增加商品
  • 回退 React 19 → 18.3.1 修复 Arco Design 兼容问题
  • 新增泰语/马来语/菲律宾语/越南语输出、AI 润色默认英文 + 语言快捷切换
  • OAuth 授权页加固（redirect_uri 白名单、非 JSON 回退拒绝、Bearer 构造）

三、聚合聊天 App（back_tk_message_app）——公司平台的一环

这个仓库本月非常活跃，是抖音客服/聚合聊天 App（公司 AIGC 平台能力之一）：

  • 协议扫码优先 + 浏览器 QR 兜底：内置 hot 协议扫码包，官方 PNG 收 cookie
  • OAuth2 多平台身份会话：9011+9012 同一人多账号合并、不同人顶掉；state 事务持久化 + 加密 PKCE
  • QR 登录并发配额：满并发排队而非立即 503，任务认领精化
  • 脚本任务队列加固：租约续期、去消费即完成、僵尸守卫、保留未确认消息
  • 未读持久化、多账号资料/设备编辑、陌生人会话直发
  • 线上部署健康验证与阶段 0-6 操作手册沉淀

四、AI Agent（xlagent）——托管与知识库中枢

这是前端的”大脑”，本月长成不少：

  • 知识库混合检索：PG 倒排 + Qdrant 稠密向量 RRF 融合，接入对话上下文
  • 托管编排强化：养号/获客脚本「守卫消费判完成」根治、僵尸状态自动兜底、手动「立即执行」强制入队、发布前审核邮件一键通过/驳回
  • 对话能力扩展：创建项目 NL、托管配置对话编辑、身份/知情记忆、用户上下文分组展示、clarify 误判守卫
  • 自然语言调用 8098 云控 + 记忆压缩 + 对话历史 8→20、280→800 runes、SSE 流式思维链与长文 30s 超时根治

五、GitHub 副业：RimWorld 模组爆发（本月隐藏主线）

工作之余在 RimWorld 模组上投入不小，8 月 7 日到 8 月 27 日堪称”模组发布季”，尤其是 8/26-27 一次性落地了多个仓库：

5.1 模组全家桶（均在创意工坊发布）

  • 愚公移山（YuGongFillsMountain / Pooi-s-Mountain-Moving）：以极高工作量移除/建造厚岩顶，Designator/WorkGiver/JobDriver + MapComponent 进度持久化 + 设置
  • 精卫填海（JingWeiFillsSea）：填海造陆，WorkGiver/Comp 双路线 + 中英本地化
  • 文化招募限制（Cultural-Ritual-Limits）：控制角色加入的人力限制，Harmony 补丁 + 调试诊断补丁
  • 自定义背景（PooiCustomBackground）：主菜单背景管理器 + 文件浏览器对话框
  • HeroBackgroundPack / 英雄背景包：批量英雄背景图
  • Hay-From-Everywhere：打草哈喽 Farm 草 → 干草
  • Never-Blow-Yourself-Up：手雷/燃烧瓶自动开火前友军安全检查

值得一提：这批模组都配了中英本地化、Preview 预览图、Steam Workshop 发布 ID，并自动 Compile 输出 Assemblies/*.dll。有些还写了配套的新手教程（基础篇 01-08 + 进阶篇 09-13）——把踩过的坑沉淀给了后来人。

5.2 心得体会

从手雷检查到逐个模组发布，这个月把 Harmony 补丁、Def XML、WorkGiver/Designator、JobDriver、本地化、创意工坊发布 这套 RimWorld 开发全流程完整走了一遍，堪称主语言之外的”第二技能树”。

六、博客

  • 新发重磅文章 《Go 底层相关八股》（7/30）：goroutine 超时管理、空接口/泛型/类型断言、接口设计、panic/recover、gRPC 选型、一致性哈希
  • 配合 B 站/术力口分区找图，更新了多篇图文配图（8/05、8/11~8/20）
  • pooiwoop.io 部署站点 7/30 更新

七、这个月 vs 上个月

维度 上个月 这个月

上月是”做出功能”，这月明显转向工程化打磨、越权修复、性能与正确性，并发掘了 RimWorld 模组这个全新的开源副业赛道。

写在最后

第二个实习月不再只是”写代码”，而是大量精力花在鉴权、越权、限流、加密、部署排障这类”看不到但出事就要命”的事上，也第一次强烈体会到降级决策（React 19 → 18.3.1）的务实。

副业方面，RimWorld 模组超出预期地高产——从初期的单发模组到 8 月底的整批发布。这种”主业修内功、副业练新招”的节奏，是这个月最好的状态。

下个月目标：

  • 把 keyword_topic_person 的性能优化沉淀成可复用查询规范
  • 托管系统打磨出更完整的”审核闭环”产品能力
  • 给 RimWorld 模组完善 CI/一键打包发布流程

继续加油。
